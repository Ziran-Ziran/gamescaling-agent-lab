## 先记住这条主线

给模型看画面 → 用示范或奖励教它选动作 → 保存学习进度 → 拿没参与训练的固定题目考试 → 与原模型比较 → 检查有没有忘旧本领、反应是否够快。

“教过它”“练完了”“考试变好”“换个游戏也会”是四件不同的事。我们的记录会分别说明。

## 后续每轮怎样更新

每个有实质结果的训练、评测、输入模态或速度里程碑，都要新增或更新相应教学记录，并更新本入口。记录至少包含：

1. 这一轮想解决什么问题，为什么现在做。
2. 实际怎样做，专业词第一次出现时用普通话解释。
3. 结果和失败说明什么，还有什么没证明。
4. 原始技术证据在哪里，下一步准备解决什么。

补写、修正和实验日期分别标明。后来的证据推翻旧解释时保留修正说明，不悄悄把历史改成一直正确。

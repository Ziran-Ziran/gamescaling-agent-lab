# 阶段路线图

| 阶段 | 内容 | 验收 | 当前状态 |
|---|---|---|---|
| 0 | 独立控制基础设施、工程与数据合同 | 单独克隆可跑离线检查 | 本轮工程拆分 |
| 1 | 训练数据转换与多游戏冻结基线 | 许可/对齐/按游戏划分可审计，端到端延迟可复现 | RGB 转换/审计及合成保存图基线已跑；真实多游戏数据与采样到执行验收未完成 |
| 2 | SFT/LoRA 训练与恢复 | 固定预算、种子、检查点、未见游戏和遗忘评测 | PEFT LoRA 已完成真实 0.8B 权重上的合成短跑与检查点；CPU 恢复一致性通过，真实任务收益/泛化/遗忘未验收 |
| 3 | 额外模态编码与融合 | 一次一模态，缺失/时序消融，权限条件分开 | 音频因果窗口/掩码及小型 CPU 融合训练已冒烟；官方 GameScaling 音频理解与真实模态收益未验收 |
| 4 | 反馈训练与 RL | 奖励可审计，比较等预算 SFT，报告失败 | 待实现 |
| 5 | 低延迟推理与调度 | 同硬件/模型对照，任务成功与P95/过期率共同改善 | 已做固定 RGB+adapter 的合并执行对照；静态小样本约 1.029x，仍约 2 秒；在线调度/真实过期率与任务保持未验收 |

训练、模态和低延迟研究可各开独立实验，但先固定数据与 RGB 基线。现有 GameScaling 官方模型作为起点，不宣称本仓库已有新模型或支持任意游戏。SITP 与 SLAM 不在必需依赖中。

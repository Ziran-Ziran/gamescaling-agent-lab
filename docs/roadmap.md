# 阶段路线图

| 阶段 | 内容 | 验收 | 当前状态 |
|---|---|---|---|
| 0 | 独立控制基础设施、工程与数据合同 | 单独克隆可跑离线检查 | 本轮工程拆分 |
| 1 | 训练数据转换与多游戏冻结基线 | 许可/对齐/按游戏划分可审计，端到端延迟可复现 | RGB 转换/审计及合成保存图基线已跑；真实多游戏数据与采样到执行验收未完成 |
| 2 | SFT/LoRA 训练与恢复 | 固定预算、种子、检查点、未见游戏和遗忘评测 | 真实 0.8B LoRA/确定性恢复通过；自有暂停式玩具环境固定 128 步后回合收益改善，商业游戏/广泛泛化/遗忘未验收 |
| 3 | 额外模态编码与融合 | 一次一模态，缺失/时序消融，权限条件分开 | 实际双图 LoRA128 八条件均8/16、无融合收益；后续冻结视觉联合新头在两套对齐条件各32/32、交换音频各0/32，四组2048实际回合；只支持人工表示可读性，原生音频/原解码器融合未验收；见 [audio-vision](audio-vision.md)、[vision-readout](vision-readout.md) |
| 4 | 反馈训练与 RL | 奖励可审计，比较等预算 SFT，报告失败 | 实际一步 bandit/SFT 各 128 更新、采样恢复和冻结对照已完成；主评测相同，均有四个 hazard 退化；八步迁移 7/8 对 6/8 不足以证明更优；顺序 RL 未实现，见 [feedback-learning](feedback-learning.md) |
| 5 | 低延迟推理与调度 | 同硬件/模型对照，任务成功与P95/过期率共同改善 | 合并约 1.029x；受限五类解码固定权重配对约 12.103x、处理 P50 163ms，新玩具集回报保持；动作空间受限，持续实时/线上过期率未验收 |

训练、模态和低延迟研究可各开独立实验，但先固定数据与 RGB 基线。现有 GameScaling 官方模型作为起点，不宣称本仓库已有新模型或支持任意游戏。SITP 与 SLAM 不在必需依赖中。

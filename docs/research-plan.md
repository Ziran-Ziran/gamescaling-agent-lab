# GameScaling 独立研究计划

长期愿景：能实时在陌生游戏中执行任务的通用玩家。本仓库研究模型本身的训练与适配、多模态表示、反馈学习，以及能力—延迟—成本权衡；不以搭接 SLAM 或完成一款游戏寻路替代该目标。

研究线一：冻结现有 RGB 策略基线，按游戏隔离数据和评测。实现可审计轨迹转换和 SFT/LoRA，比较未适配、等预算适配，并测已见/相关未见/差异较大未见游戏；记录是否损伤原有能力。

研究线二：一次增加一个模态，比较 RGB、RGB+audio、RGB+depth、RGB+engine_state；训练/部署权限固定。加入模态缺失、时间错位与噪声消融。后端状态可能减少感知成本，但信息优势和编码开销须分开报告；player_observation 和 privileged 条件不能混排。

研究线三：固定模型与算力，比较同步决策、有限异步、事件触发/自适应思考；报告采样到执行 P50/P95、过期率、任务成绩和资源成本，不能只看服务端请求耗时。先测端到端瓶颈再选择量化、蒸馏或结构改造。

研究线四：实现环境反馈与可复现奖励后，再比较 SFT 与 RL/其他后训练；锁定样本数、交互步数和算力，记录失败恢复与奖励投机。模型能按键与能完成任务分别验收。

已增加独立 RGB 轨迹审计/转换、保存图评测与 PEFT LoRA 训练/恢复入口，详见 [training.md](training.md)。合成冒烟验证工程链路，与真实游戏任务收益、泛化、遗忘和额外模态理解分别验收。GPU 训练、下载和真实游戏输入需对应任务授权，不能由 CI 或静态配置检查自动启动。
